Detailed Description

Component that attaches a Lua script to a Node.

ScriptComponent connects a scene Node to a Lua script. It stores the path to the associated script and forwards script lifecycle operations to the ScriptSystem.

A Lua script attached through a ScriptComponent can implement behavior such as movement, animation, interaction, or other game-specific logic. The component participates in the Node lifecycle through its Start() and Update() functions.
