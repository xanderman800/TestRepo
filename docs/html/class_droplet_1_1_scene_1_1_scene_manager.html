Detailed Description

Manages the Scenes used by the application.

SceneManager is responsible for loading, unloading, activating, and deactivating Scenes. It also updates and renders all currently active Scenes.

Loaded Scenes are stored using shared ownership, while the list of active Scenes uses weak references to avoid additional ownership.
