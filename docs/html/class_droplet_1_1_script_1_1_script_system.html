Detailed Description

Provides the main interface for the engine's Lua scripting system. ScriptSystem manages the lifecycle of scripts and coordinates between the Lua state and the ScriptManager. It is responsible for starting and updating the scripting system, loading and unloading script files, and creating, activating, deactivating, and destroying script instances.
