Detailed Description

Represents a game object in a scene hierarchy.

A Node can contain child Nodes and Components and has a local transform relative to its parent. Its world transform is calculated from its local transform and the transform of its parent.

Nodes are managed using shared ownership and maintain a weak reference to their parent to avoid ownership cycles.

Adds a Component to the Node.

Constructs the Component using the provided arguments, assigns this Node as its owner, and stores it.

If the Component provides a bounds override, it is registered as the Node's bounds provider. A Node can only have one Component providing a bounds override.

If the Node has already been started, the Component is started immediately.

Multiple Components of the same type can be attached to a Node.

◆ Start()

void Node::Start ( )

Starts the Node, its Components, and its children.

Calls OnStart() on all Components attached to this Node and then starts all child Nodes.

OnStart() is called at most once for each Node. Nodes that are added to an already started Node are started immediately.

Note
The Node's Start() function can be overridden by derived Nodes.
