Detailed Description

Represents an instance of a Lua script and its execution environment. A ScriptInstance associates a Lua script with a ScriptComponent and provides an isolated Lua environment in which the script is executed. It provides functions for calling arbitrary Lua functions as well as the standard OnStart and OnUpdate lifecycle functions.
