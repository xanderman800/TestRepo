Template Parameters

Parameters
p_deviceVulkan Device
p_queueThe queue to submit the command to.
p_recordFunctionFunction to be invoked while the command buffer is recorded.
Precondition
The queue represented by p_queue must be compatible with the queue family used by this pool.
p_recordFunction must be passed with a CommandBuffer as a parameter.
Note
This function blocks until the queue is idle.
