Detailed Description

A frustum is a geometric shape that represents the visible area of a camera in 3D space. It is defined by six planes: left, right, top, bottom, near, and far.

void Frustum::GetCorners ( glm::vec3 * p_corners) const

Calculates the eight corners of the frustum and stores them in the provided array.

Parameters
p_cornersAn array of eight glm::vec3 objects to store the corners of the frustum.

Corners are ordered as follows: (left, top, near) (right, top, near) (left, bottom, near) (right, bottom, near) (left, top, far) (right, top, far) (left, bottom, far) (right, bottom, far)
