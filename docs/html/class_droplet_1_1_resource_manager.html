◆ UpdateMetaEntry()

bool Droplet::ResourceManager::UpdateMetaEntry ( GUID p_guid,
const MetaEntry & p_updatedEntry,
bool hotReload = true )

Updated the meta entry for a specific resource and optionally triggers a hot-reload of that resource.

Note
This function will reject updates if the resource is currently being loaded or uploaded.
Parameters
p_guidThe globally unique identifier of the resource.
p_updatedEntryThe modified metadata entry.
hotReloadIf true, the resource is hot-reloaded from disk using the new meta entry settings.
Returns
True if the entry was successfully updated and written to disk. False if resource was loading, uploading, or if GUID does not relate to any registered resource.
