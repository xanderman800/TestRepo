Detailed Description

Base class for game-level behaviours.

Behaviour provides a common interface for logic that is attached to the game. The main distinction is that Components are attached to Nodes, while Behaviours are attached to the game and can operate on the scene through the SceneManager.

Behaviours can be derived from to implement game-level systems or logic that should not belong to a specific Node or Component.

As behaviours are not serialized with scenes, they are not automatically suited for tasks that require persistent data across runtimes.
