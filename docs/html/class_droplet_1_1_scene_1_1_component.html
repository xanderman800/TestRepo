Detailed Description

Base class for components that can be attached to a Node.

Components provide reusable functionality that can be added to Nodes at runtime. Derived components can override Initialize(), OnStart(), and Update() to implement their own behavior.

Components are owned by the Node they are attached to. A Component maintains a weak reference to its owning Node to avoid an ownership cycle.
