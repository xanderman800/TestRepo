enum class Droplet::UpdateFlags : std::uint32_t
strong

UpdateFlags are used to control the execution steps of the frame loop.

Certain functionality may be skipped or modified in case the default frame loop logic is not desired.

For example, node + behaviour + script logic and automatic rendering should be disabled in the Editor.
